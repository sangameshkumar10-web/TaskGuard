# TaskGuard 🛡️

**TaskGuard** is a cybersecurity-themed daily productivity and task management application designed to help users organize tasks, manage deadlines, and stay on track with timely reminders and notifications.

## ✨ Features

* **Task Management** — Create, organize, update, and track daily tasks.
* **Deadline Tracking** — Keep track of upcoming deadlines and task status.
* **Reminders & Notifications** — Get notified about important tasks and deadlines.
* **Dashboard** — View and manage your productivity from a centralized interface.
* **Settings** — Configure available application preferences.
* **Desktop Application** — Access productivity features through the desktop application.
* **Cybersecurity-Inspired UI** — A security-themed interface with a modern technical aesthetic.

## 🛠️ Technology Stack

TaskGuard is organized into the following components:

* **Frontend:** React and TypeScript
* **Backend:** Python and FastAPI
* **Desktop:** Electron
* **Testing:** Pytest
* **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Install the tools required by the components you intend to run:

* Python
* Node.js and npm
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sangameshkumar10-web/TaskGuard.git
   ```

2. Enter the project directory:

   ```bash
   cd TaskGuard
   ```

3. Review the frontend, backend, and desktop directories for their respective setup instructions.

4. Install the required dependencies and configure environment variables according to the project's configuration files.

5. Start each component using the commands documented in its directory.

> **Note:** Exact installation and startup commands depend on the current project configuration. Consult the relevant package files and backend requirements before running the application.

## 🧪 Testing

TaskGuard includes a `tests/` directory and a `pytest.ini` configuration file.

To run the applicable Python tests after installing the project's dependencies:

```bash
pytest
```

## 🔐 Security

* Never commit API keys, passwords, tokens, or secret environment variables.
* Keep local `.env` files out of version control.
* Use secure configuration practices when deploying the application.
* Test only systems for which you have authorization.

## 🎯 Project Goal

TaskGuard aims to combine everyday productivity with a cybersecurity-inspired user experience, making it easier to manage tasks, track deadlines, and stay organized.
